## 🚀 HOW TO USE

### Step 1: Add Training Data
Place your medical datasets in:
```
data/raw/
```

### Step 2: Run Individual Model Training
Train a specific model:
```bash
python backend/models/cardiology_model.py
python backend/models/dermatology_model.py
# etc...
```

### Step 3: Run Full Retraining
Retrain all 7 models at once:
```bash
python scripts/retrain_models.py
```

### Step 4: Check Results
View results in:
```
outputs/reports/training_results.json
outputs/logs/training_log_*.txt
outputs/graphs/
```
